# CLM-Bench: Cross-Lingual Misalignment Benchmark

A culture-aware benchmark for evaluating cross-lingual knowledge editing in Large Language Models (LLMs). CLM-Bench contains 1,010 high-quality Chinese-first CounterFact pairs spanning 24 domains, designed to reveal cross-lingual misalignment in knowledge editing methods.
